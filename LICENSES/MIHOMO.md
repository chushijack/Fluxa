# Mihomo (Clash.Meta)

Fluxa embeds mihomo through the Git submodule at `core/Clash.Meta` (remote: https://github.com/chen08209/Clash.Meta, branch `FlClash`).

After initializing the submodule:

```bash
git submodule update --init core/Clash.Meta
```

the upstream license file is at `core/Clash.Meta/LICENSE` (GPL-3.0 at time of phase-0 setup).

Release builds must comply with GPL-3.0 for this component and provide corresponding source as required.
